# NEON GALAXY: HUNTER

A futuristic beginner-friendly 3D browser driving and combat game.

## Game brief
- Dark, minimalist neon/galaxy atmosphere inspired by futuristic sci-fi racing aesthetics
- Responsive, detailed futuristic sports car
- WASD to drive; Space to brake; J to fire homing light missiles
- Five uniquely styled enemy cars to defeat
- Beginner level with win condition after destroying all five enemies
